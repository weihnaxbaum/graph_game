# Graph Game

A game in which you have to correctly connect the vertices of a graph, made using [Bevy Engine](https://bevy.org).

The levels and sounds are procedurally generated.

[graph_game.webm](https://github.com/user-attachments/assets/4e6dcc5e-ba4f-4768-a71c-a49e09db0adb)

## Building

1. Install [Bevy's dependencies](https://bevy.org/learn/quick-start/getting-started/setup/#installing-os-dependencies)
2. `cargo build` or `cargo run` (use `--release --no-default-features` for release builds)
